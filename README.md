# 📈 Marketing Analytics – CAC, LTV and ROMI Analysis

Projeto de Análise de Dados desenvolvido em **Python** para avaliar o desempenho de campanhas de marketing por meio de métricas essenciais como **CAC**, **LTV** e **ROMI**, auxiliando na tomada de decisões estratégicas.

---

# 📌 Objetivo

Analisar o comportamento dos usuários e o desempenho das campanhas de marketing, calculando indicadores de aquisição, retenção e retorno sobre investimento para identificar os canais mais eficientes.

---

# 📖 Descrição do Projeto

Este projeto utiliza dados de visitas, pedidos e custos de marketing para avaliar a eficiência das campanhas de aquisição de clientes.

Foram analisadas métricas fundamentais do marketing digital, permitindo compreender o retorno financeiro das campanhas e fornecer recomendações para otimizar o investimento em marketing.

---

# 🔎 Metodologia

O projeto foi desenvolvido seguindo as seguintes etapas:

- Importação e preparação dos dados;
- Limpeza e tratamento das bases;
- Análise Exploratória dos Dados (EDA);
- Cálculo do CAC (Customer Acquisition Cost);
- Cálculo do LTV (Lifetime Value);
- Cálculo do ROMI (Return on Marketing Investment);
- Comparação entre canais de aquisição;
- Interpretação dos resultados e recomendações.

---

# 📊 Resultados

A análise permitiu:

- Identificar os canais de marketing mais eficientes;
- Comparar o custo de aquisição de clientes;
- Calcular o valor gerado pelos clientes ao longo do tempo;
- Avaliar o retorno financeiro das campanhas;
- Apresentar recomendações para otimização do orçamento de marketing.
