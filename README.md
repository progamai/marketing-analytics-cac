# 📈 Marketing Analytics – CAC, LTV e ROMI

Projeto de análise de marketing utilizando Python para avaliar métricas fundamentais de aquisição e retenção de clientes.

## Objetivos

- Calcular CAC (Customer Acquisition Cost)
- Calcular LTV (Lifetime Value)
- Calcular ROMI (Return on Marketing Investment)
- Analisar comportamento dos usuários
- Avaliar desempenho das campanhas de marketing

## Tecnologias utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
